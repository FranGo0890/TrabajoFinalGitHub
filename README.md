## Objetivo
Creación de un e-commerce orientado a la venta de materiales eléctricos e iluminación
## Como moverte de Rama en Git
```bash
git switch <nombre-de-rama>
```
## Flujo de Colaboración (Workflow)

En este proyecto utilizamos la metodología de trabajo basada en **Feature Branching**, **Issues** y **Pull Requests**:
1. **Issues:** Cada tarea o funcionalidad pendiente se registra como un Issue en GitHub para llevar un control organizado.
2. **Feature Branches:** Por cada tarea, creamos una rama independiente desde la terminal utilizando git (por ejemplo, `git switch -c feature/nombre-de-rama`).
3. **Pull Requests:** Una vez finalizados los cambios en la rama de feature, subimos el código al repositorio remoto y abrimos un Pull Request para revisarlo y fusionarlo (`merge`) con la rama `main`.
